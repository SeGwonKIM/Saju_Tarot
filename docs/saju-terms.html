요청 한 번의 여정

원래 요청 하나로 끝냈다가 v3.0에서 둘로 갈랐습니다. 계산은 즉시 끝나는데 LLM 문장 생성이 14초라, 한 요청에 묶으면 손님이 빈 화면을 14초 봅니다.

POST /readings 계산 — 공짜, 즉시 약 0.2초
입력 검증 → 음↔양 변환 → 한국 시간 보정 → 사주 4주·오행 → 타로 3장 → 암호화 저장

이 단계까지는 LLM이 전혀 개입하지 않습니다. 전부 계산으로 확정된 사실입니다.

POST /readings/{id}/report 풀이 — 돈이 드는 쪽 약 14초
레이트리밋 검사 → 사실 + 말투 샘플로 프롬프트 → LLM 호출 → 스키마 검증 → 저장

건당 약 50원. 실패해도 500이 아니라 report=null로 계산 결과만 돌려줍니다.

REST API Representational State Transfer

주소(URL)와 동사(GET·POST)를 정해 두고 정해진 모양의 데이터를 주고받는 약속.

비유 식당 메뉴판. 무엇을 어떤 이름으로 주문할 수 있는지 미리 적혀 있다.

이 프로젝트 GraphQL 대신 REST. 화면이 3개고 응답 모양이 고정이라 "필드 골라 받기"가 필요 없었다.

엔드포인트 endpoint

서버가 열어 둔 창구 하나. 주소 + 방식(GET/POST)의 조합.

비유 은행 창구 번호. 입금 창구와 대출 창구가 다르다.

이 프로젝트 11개. 계산·풀이·조회·삭제·공유·달력 변환·헬스체크·상담자 목록.

FastAPI

파이썬 웹 프레임워크. 함수에 붙인 타입을 그대로 입력 검증과 API 문서로 바꿔 준다.

비유 주문서 양식을 만들면 접수 담당과 안내문이 같이 딸려 오는 것.

이 프로젝트 타입 힌트가 곧 계약이라, 프론트의 zod 스키마와 짝이 맞는지 눈으로 대조할 수 있다.

ASGI / uvicorn

파이썬 웹 앱을 실제로 실행해 요청을 받아 주는 프로그램(과 그 규격).

비유 FastAPI가 요리사라면 uvicorn은 가게 문을 열고 손님을 받는 사람.

이 프로젝트 배포 이미지에서 --no-server-header로 실행 — 서버 종류를 숨긴다.

pydantic

들어온 값이 정해진 모양인지 검사하고, 아니면 거절하는 라이브러리.

비유 서류 접수대. 칸이 비었거나 형식이 틀리면 접수 자체를 안 받는다.

이 프로젝트 설정에도 쓴다 — 필수 환경변수가 없으면 서버가 아예 부팅되지 않는다.

OpenAPI / /docs

API의 모든 창구와 데이터 모양을 기계가 읽는 형식으로 적어 둔 명세서.

비유 건물 도면. 편리하지만 침입자에게도 편리하다.

이 프로젝트 운영에서는 /docs와 /openapi.json을 둘 다 닫는다. docs만 닫으면 json으로 그대로 샌다.

미들웨어 middleware

모든 요청이 반드시 통과하는 중간 관문. 본 처리 전후에 공통 작업을 한다.

비유 건물 정문의 보안 검색대. 어느 사무실을 가든 여기를 지난다.

이 프로젝트 4겹 — 요청 크기 제한 → 보안 헤더 → 레이트리밋 → 추적 ID·로그.

CORS

브라우저가 "다른 주소의 서버를 부르는 것"을 막는 규칙. 서버가 허락 목록을 준다.

비유 옆 건물 사람을 들일지 정문에서 명단으로 확인하는 것.

이 프로젝트 화면과 API가 같은 주소라 사실상 필요 없다. 그래도 와일드카드 금지 규칙은 지켜 실제 주소를 적어 뒀다.

단일 오리진 same origin

화면(HTML)과 API를 한 서버가 같은 주소로 함께 내보내는 구조.

비유 주방과 홀이 한 건물. 배달 계약이 필요 없다.

이 프로젝트 원래 프론트·백·DB 3분할 계획이었는데 이걸로 바꾸면서 CORS·터널·배포가 모두 단순해졌다.

HTTP 상태 코드

응답 첫 줄에 붙는 세 자리 숫자. 성공·실패의 종류를 알린다.

비유 병원 접수 결과 도장. "완료" "서류 미비" "그런 과 없음".

이 프로젝트 400 형식 오류 · 404 없음(또는 숨김) · 413 본문 과대 · 422 달력상 불가능한 날짜 · 429 한도 초과.

SQLite

서버 프로그램 없이 파일 하나가 곧 데이터베이스인 방식.

비유 창고를 따로 빌리지 않고 튼튼한 서랍 하나를 쓰는 것.

이 프로젝트 Supabase(PostgreSQL) 계획을 접고 이걸로. 외부 서비스도 키도 없고 백업이 파일 복사 한 번.

React / 컴포넌트

화면을 재사용 가능한 조각으로 쪼개 조립하는 방식.

비유 레고 블록. 카드 한 장을 만들어 78번 쓴다.

이 프로젝트 21개 파일. 타로 부채꼴·오행 막대·기둥 표가 각각 독립 조각.

TypeScript

자바스크립트에 "이 값은 숫자" 같은 타입을 붙여, 실행 전에 오류를 잡는 언어.

비유 맞춤법 검사기. 보내기 전에 빨간 줄이 뜬다.

이 프로젝트 tsc -b가 빌드 전에 돈다. 타입이 안 맞으면 배포 이미지가 만들어지지 않는다.

번들 bundle

여러 소스 파일을 브라우저가 받기 좋게 하나로 묶어 압축한 결과물.

비유 이삿짐을 상자 몇 개로 합치는 것. 열어 보면 안에 다 들어 있다.

이 프로젝트 여기에 비밀값이 섞이면 그대로 공개된다. 그래서 빌드 직후 정규식 7종으로 번들을 스캔한다.

TanStack Query

서버에서 받아 온 데이터의 로딩·오류·캐시를 대신 관리해 주는 라이브러리.

비유 주문 현황판. 조리 중인지, 나왔는지, 취소됐는지를 화면이 알아서 안다.

이 프로젝트 14초짜리 풀이 요청의 "기다리는 중" 상태를 화면 곳곳에서 일관되게 쓰기 위해.

zod / 스키마

데이터의 모양을 코드로 적어 두고, 그 정의로 검사·타입 생성까지 하는 도구.

비유 서류 양식 원본. 접수처·복사본·검토자가 전부 같은 양식을 본다.

이 프로젝트 "계약 단일 출처". 스키마 하나가 폼 검증 + 목업 데이터 + 서버 응답 파싱을 전부 담당한다.

목업 mock

아직 없는(또는 느린) 진짜 대신 끼워 넣는 가짜 데이터·가짜 응답.

비유 모델하우스. 사람은 못 살지만 구조는 그대로다.

이 프로젝트 서버보다 화면을 먼저 만들었다. 위험은 기본값이 "목업 켬"이라는 것 — 배포 시 끄는 줄이 빠지면 가짜 리포트가 나간다.

만세력 萬歲曆

양력·음력·절기·간지를 한데 묶어 놓은 날짜 표. 사주 계산의 원재료.

비유 천문·역법 사전. 사주는 이 사전을 찾는 일에서 시작한다.

이 프로젝트 표를 직접 만들지 않고 라이브러리 둘을 쓰되, 둘 다 그대로는 틀려서 보정층을 얹었다.

원국 / 사주 4주 四柱

태어난 연·월·일·시를 각각 두 글자로 바꾼 여덟 글자. 사주팔자의 그 팔자.

비유 태어난 순간의 좌표 네 쌍.

이 프로젝트 계산 결과는 확정된 사실로 취급하고, LLM은 그것을 문장으로 옮기기만 한다.

천간·지지 / 60갑자 干支

천간 10글자와 지지 12글자를 짝지어 만든 60개의 순환 이름표.

비유 톱니 두 개(10칸·12칸)를 맞물려 돌리면 60번 만에 처음으로 돌아온다.

이 프로젝트 라이브러리가 계산하고, 우리는 어떤 시각을 넣을지만 정확히 정한다.

절기 節氣

태양의 위치로 나눈 24개의 계절 마디. 사주의 달은 음력이 아니라 절기로 바뀐다.

비유 달력의 1일이 아니라 입춘·경칩 같은 자연의 눈금이 월을 가른다.

이 프로젝트 라이브러리는 절기를 베이징 기준으로 계산한다. 그대로 쓰면 경계 근처 출생자의 연주·월주가 틀린다.

진태양시 眞太陽時

시계가 아니라 그 자리에서 해가 실제로 남중하는 시각 기준의 시간.

비유 손목시계 대신 해시계를 보는 것.

이 프로젝트 시주(자시 23~01시)는 태양 기준이라 경도가 결과를 바꾼다. 그래서 일·시주는 진태양시로 계산한다.

표준자오선 標準子午線

한 나라의 시계를 맞추는 기준 경도선.

비유 전국이 같은 시각을 쓰려고 정한 대표 지점.

이 프로젝트 한국은 역사적으로 동경 135°↔127.5°를 오갔다. 태어난 시기에 따라 환산이 달라진다.

서머타임 DST

여름에 시계를 한 시간 앞당기던 제도. 한국도 몇 차례 시행했다.

비유 온 나라가 한 시간 일찍 출근하기로 약속한 기간.

이 프로젝트 보정 1단계가 이것 — 시행 구간 출생이면 시계 시각에서 1시간을 뺀다. 표는 아직 잠정값이라 릴리스 전 검증이 숙제.

조자시 · 야자시 朝子時 夜子時

밤 23~24시를 그날로 볼지 다음 날로 볼지 — 유파마다 다른 판정.

비유 자정 직전 손님을 오늘 예약으로 칠지 내일로 칠지의 규칙 차이.

이 프로젝트 기본값은 조자시. 코드에서 바꿀 수 있게 열어 뒀다.

지장간 支藏干

지지 한 글자 안에 숨어 있는 천간들. 오행을 셀 때 가중치를 어떻게 줄지가 쟁점.

비유 겉으로 한 명이지만 안에 여러 지분이 섞여 있는 것.

이 프로젝트 가중치 정책은 우리가 정한 결정이라고 PRD에 명시했다. 라이브러리가 준 값이 아니다.

오행 五行

목·화·토·금·수 다섯 기운. 여덟 글자를 이 다섯으로 집계해 균형을 본다.

비유 영양 성분표. 무엇이 넘치고 무엇이 모자란지.

이 프로젝트 화면의 막대그래프가 이 집계다. 이 페이지의 분류 색도 여기서 가져왔다.

일간 · 십성 日干 十星

일간은 사주에서 '나'에 해당하는 글자, 십성은 나머지 글자와 나의 관계.

비유 가족 관계도에서 '나'를 정하고 나머지를 부모·형제로 부르는 것.

이 프로젝트 "무진 병진"만 보여주면 손님이 못 읽는다. 그 사이를 메우려고 만든 계산.

신강 · 신약 身强 身弱

일간의 힘이 센지 약한지 판정. 사주 해석의 큰 갈래.

비유 같은 지표라도 학교마다 합격선이 다른 것.

이 프로젝트 일부러 빼놨다. 득령·득지·득세를 보는 법이 유파마다 달라 한쪽을 고르면 그 자체가 오답이 된다.

윤달 閏月

음력에서 계절이 밀리지 않도록 몇 년에 한 번 끼워 넣는 여벌 달.

비유 양력의 2월 29일을 한 달 통째로 하는 것.

이 프로젝트 라이브러리가 없는 윤달에도 "있다"고 답한다. 조용히 틀린 결과가 나오는 최악의 종류.

왕복 검증 round-trip

변환한 값을 되돌려 원본과 같은지 확인하는 방법.

비유 번역문을 다시 원어로 옮겨 보고 뜻이 맞는지 확인하는 것.

이 프로젝트 음→양→음. 되돌린 날짜가 다르면 그 윤달은 존재하지 않는 것으로 판정한다.

골든 테스트 golden test

정답을 미리 확정해 두고 결과가 그것과 같은지 보는 시험.

비유 모범 답안지와 대조 채점.

이 프로젝트 사람이 100건 만드는 대신 KASI 절기 API와 1900~2050년 약 3,600건을 자동 전수 대조했다.

대운 · 세운 大運 歲運

10년 단위(대운)와 그 해(세운)의 흐름.

비유 원국이 지형이라면 이쪽은 계절과 날씨.

이 프로젝트 리포트의 "이번 달 흐름"이 여기서 나온다. 화면 순서를 사주 풀이 바로 다음으로 옮겼다.

LLM Large Language Model

엄청난 양의 글을 학습해 다음에 올 말을 확률로 고르는 모델.

비유 말솜씨는 뛰어나지만 계산은 못 미더운 작가.

이 프로젝트 계산은 절대 안 시킨다. 확정된 사실을 넘기고 문장만 쓰게 한다.

프롬프트 prompt

모델에게 주는 지시문 전체. 규칙·자료·출력 형식이 다 들어간다.

비유 작가에게 넘기는 취재 자료 + 원고 청탁서.

이 프로젝트 템플릿을 PRD §11.4에 문서로 박아 뒀다. 코드에만 두면 아무도 못 본다.

few-shot

원하는 결과의 예시 몇 개를 프롬프트에 함께 넣어 흉내 내게 하는 방법.

비유 "이런 느낌으로 써 주세요" 하며 샘플 원고를 보여주는 것.

이 프로젝트 실제 상담 말투 샘플을 넣되 5건 미만이면 적용 안 함 — 표본이 적으면 문장을 통째로 베낀다.

구조화 출력 structured output

자유 문장이 아니라 정해진 항목·형식(JSON)으로만 답하게 강제하는 것.

비유 서술형 대신 빈칸 채우기 답안지를 주는 것.

이 프로젝트 출력 스키마를 고정. 형식이 어긋나면 받아들이지 않고 부분 성공으로 처리한다.

enum 열거형

허용되는 값을 목록으로 못 박는 타입.

비유 객관식. 보기 밖의 답은 쓸 수 없다.

이 프로젝트 프롬프트로 "주제 5개만" 부탁했더니 모델이 요청하지 않은 "종합" 항목을 지어냈다. 그래서 enum으로 막았다.

환각 hallucination

모델이 사실이 아닌 것을 자신 있게 지어내는 현상.

비유 모르는 걸 모른다고 안 하고 그럴듯하게 말하는 사람.

이 프로젝트 카드 뜻을 코드 표에 두고 키워드만 넘긴다. 카드 의미를 스스로 짓지 못하게.

어댑터 / 프로토콜 adapter

바깥 서비스를 우리가 정한 인터페이스 뒤에 숨겨, 갈아 끼울 수 있게 하는 설계.

비유 해외여행용 콘센트 어댑터. 벽면 규격이 바뀌어도 기기는 그대로.

이 프로젝트 ReportGenerator 하나. 지금은 OpenAI지만 Claude로 바꿔도 고칠 곳이 한 군데다.

부분 성공 graceful degradation

일부가 실패해도 전체를 실패로 만들지 않고, 되는 만큼 돌려주는 처리.

비유 디저트가 품절이면 주문 전체를 취소하지 않고 본식은 낸다.

이 프로젝트 LLM이 죽어도 500이 아니다. 계산 결과는 이미 유효하므로 그것만 보낸다.

seed / 재현성

난수의 출발점을 저장해 두면 같은 입력에 항상 같은 결과가 나오게 만드는 것.

비유 카드를 섞은 순서를 적어 두는 것. 언제 다시 펼쳐도 그 순서다.

이 프로젝트 요구사항이다 — 공유 링크를 다시 열었을 때 카드가 바뀌면 상담이 성립하지 않는다.

비복원 추출

한 번 뽑은 것은 다시 넣지 않고 뽑는 방식.

비유 로또. 같은 번호가 두 번 나오지 않는다.

이 프로젝트 78장에서 3장. 세 자리(현재·조언·방향)에 같은 카드가 겹치면 안 된다.

AES-256-GCM

널리 쓰이는 대칭키 암호. 내용을 가리는 동시에 변조 여부까지 검출한다.

비유 잠금장치 + 봉인 스티커. 열렸는지도 알 수 있다.

이 프로젝트 이름·생년월일·시각에 적용. DB 파일이 통째로 새도 이 값들은 안 읽힌다.

논스 nonce

암호화할 때마다 새로 쓰는 일회용 값. 재사용하면 암호가 깨진다.

비유 일회용 비밀번호. 같은 걸 두 번 쓰면 의미가 없다.

이 프로젝트 필드마다 새 nonce. 저장 형식은 base64(nonce + 암호문).

필드 암호화

DB 전체가 아니라 민감한 칸만 골라 암호화하는 것.

비유 서류철 전체가 아니라 주민번호 칸만 검게 덮는 것.

이 프로젝트 키를 잃으면 복호화 불가. 그래서 자동 백업은 키를 백업에 넣지 않고, 키는 비밀번호 관리자에 따로 둔다.

인증 vs 인가 401 / 403

인증은 "누구인가", 인가는 "그걸 할 권한이 있는가".

비유 신분증 확인(인증)과 출입 등급 확인(인가)은 다른 절차다.

이 프로젝트 로그인 자체가 없어 인증은 없다. 상담자 전용 창구만 토큰으로 인가를 건다.

404로 숨기기

권한이 없을 때 "권한 없음(401)" 대신 "그런 것 없음(404)"으로 답하는 방식.

비유 잠긴 문에 "관계자 외 출입금지" 팻말을 붙이지 않는 것. 문이 있는 줄도 모르게.

이 프로젝트 상담자 목록 창구에 적용. 다만 이건 보조 수단이지 잠금장치 자체가 아니라는 반론이 있다.

CSP Content Security Policy

이 페이지가 어디서 온 스크립트·글꼴·이미지를 실행해도 되는지 브라우저에 알리는 목록.

비유 출입 허가 업체 명단. 명단에 없으면 로비에서 막힌다.

이 프로젝트 지시자 9개. frame-ancestors 'none'으로 다른 사이트가 우리를 iframe에 못 넣게 막는다.

레이트리밋 rate limit

같은 사람이 정해진 시간에 부를 수 있는 횟수를 제한하는 것.

비유 1인당 구매 수량 제한.

이 프로젝트 2층 — 돈 드는 풀이는 빡빡하게, 공짜지만 디스크를 채우는 계산은 느슨하게, 조회는 안 센다.

환경변수 / .env

API 키처럼 코드에 적으면 안 되는 값을 실행 환경에 따로 넣어 주는 방식.

비유 금고 비밀번호를 설명서에 적지 않고 따로 전달하는 것.

이 프로젝트 절대경로로 읽는다. 상대경로면 서버를 어디서 띄웠느냐에 따라 키가 조용히 비어 문장 생성이 통째로 빠진다.

pre-commit 훅

커밋이 만들어지기 직전에 자동 실행되는 검사. 걸리면 커밋을 거부한다.

비유 출국 심사. 통과 못 하면 비행기를 못 탄다.

이 프로젝트 유출 차단 1차 방어. .env·*.key·*.pem은 스테이징 자체가 거부된다.

CVE / pip-audit

공개된 취약점 번호와, 설치된 패키지가 거기 걸리는지 검사하는 도구.

비유 리콜 대상 부품 목록과 대조 점검.

이 프로젝트 버전을 고정하고 올린 이유를 주석으로 남겼다 — starlette 9건, python-dotenv, pytest.

최소 권한 least privilege

필요한 만큼만 권한을 주는 원칙.

비유 청소 담당에게 금고 열쇠까지 주지 않는 것.

이 프로젝트 컨테이너를 루트가 아닌 사용자로 돌린다. 뚫려도 할 수 있는 일이 줄어든다.

로그 마스킹

기록에 남기면 안 되는 값을 별표로 가리거나 아예 안 남기는 것.

비유 CCTV는 돌리되 비밀번호 누르는 손은 안 찍히게.

이 프로젝트 남기는 것은 방식·경로·상태·소요시간·추적ID뿐. 이름·생년월일·토큰·키는 걸러진다.

하드 삭제 hard delete

"삭제됨" 표시만 남기는 게 아니라 데이터를 실제로 지우는 것.

비유 휴지통에 넣는 것과 파쇄기에 넣는 것의 차이.

이 프로젝트 보관 기간이 지나면 진짜로 지운다. 개인정보는 "가지고 있지 않은 것"이 가장 안전하다.

DPAPI

윈도우가 제공하는 암호 보관 기능. 같은 PC·같은 사용자에서만 풀린다.

비유 그 집 문에서만 열리는 열쇠. 훔쳐 가도 다른 집에서는 안 열린다.

이 프로젝트 자동 백업이 무인으로 돌려면 암호가 필요해서 쓴다. 대신 백업에 암호화 키는 넣지 않는다.

Docker / 이미지

프로그램과 실행에 필요한 것 전부를 한 덩어리로 묶어, 어디서든 같게 돌아가게 만드는 방식.

비유 주방을 통째로 담은 컨테이너. 어느 항구에 내려도 같은 음식이 나온다.

이 프로젝트 "내 PC에서는 되는데요"를 없애기 위해. 화면 빌드와 서버 실행이 한 이미지에 들어간다.

멀티스테이지 빌드

빌드용 도구는 앞 단계에서만 쓰고, 최종 이미지에는 결과물만 담는 방식.

비유 공사 후 비계를 철거하고 건물만 남기는 것.

이 프로젝트 1단계 Node로 화면 빌드 → 2단계 Python 서버에 결과물만 복사. 이미지가 작고 공격면도 줄어든다.

Blueprint render.yaml

배포 설정을 클릭이 아니라 파일로 적어 저장소에 두는 것.

비유 조립 설명서를 상자에 같이 넣는 것.

이 프로젝트 비밀값만 sync: false로 빼고 나머지는 파일에. 다시 배포해도 같은 구성이 재현된다.

영구 디스크 persistent disk

컨테이너가 재시작해도 남아 있는 저장 공간.

비유 호텔 방은 매번 바뀌지만 짐은 보관함에 두는 것.

이 프로젝트 무료 플랜에는 없다. 재배포하면 SQLite 파일이 사라진다 — 유료 전환 시 풀 주석이 대기 중.

헬스체크 / 콜드 스타트

서버가 살아 있는지 묻는 창구, 그리고 잠들었던 서버가 첫 요청에 느리게 깨는 현상.

비유 셔터를 내렸다 다시 올리는 데 걸리는 시간.

이 프로젝트 /api/v1/health를 예열용으로 둔다. 무료 플랜은 잠들기 때문에 첫 손님이 느리다.

터널 tunnel

공인 IP나 포트 개방 없이, 바깥에서 내 PC의 서버에 닿게 해 주는 중계.

비유 우리 집 주소를 알리지 않고 사서함으로 손님을 받는 것.

이 프로젝트 Cloudflare 터널. 무료라 재연결마다 주소가 바뀌어서, 바뀐 주소를 파일에 자동으로 적는다.

백업 검증

백업을 만든 뒤 실제로 열어서 복구 가능한지 확인하는 절차.

비유 소화기를 사 두는 것과, 정말 분사되는지 시험해 보는 것의 차이.

이 프로젝트 만든 자리에서 바로 열어 검사한다. 파일 복사가 아니라 SQLite 백업 API를 써 서버가 돌아도 안전하다.

회귀 테스트 pytest

고친 곳 말고 멀쩡하던 곳이 망가지지 않았는지 자동으로 확인하는 시험.

비유 한 군데 수리한 뒤 차 전체를 점검하는 것.

이 프로젝트 155개. 절기·저장·레이트리밋·리포트 형식이 각각 잠겨 있다.
